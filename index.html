# Hand Tracking with MediaPipe and Canvas # This project uses MediaPipe's hand tracking solution to detect and visualize hand landmarks in real-time using a webcam feed. The detected hands are drawn on a canvas with neon effects, and the application calculates the frames per second (FPS) for performance monitoring. ### Features # Detects up to two hands in real-time. # Visualizes hand landmarks and connections with neon effects. # Displays the number of hands detected and the current FPS. # Detects simple hand gestures (Open Hand, Fist, Point, Pinch, Partial). # python -m http.server 8000 to run the code in the terminal and then open the browser and go to http://localhost:8000 to see the hand tracking in action.
